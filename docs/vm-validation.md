# 虛擬機與實機驗收

這份清單只供使用者在測試用 Windows x64 虛擬機／內測機執行。開發機不得安裝驅動、改預設播放裝置、向實體裝置播放測試音或建立啟動項。`dist/drivers/` 只保留上游原檔；本程式沒有安裝或啟停裝置節點的命令，這些由會話 B 的 1U 測試版提供。

公開原始碼與對應版本尚未就緒前，不對外散布測試包。下面的每一條結果都必須填 PASS／FAIL 與實際觀察，不能以「沒有回報」視為通過。

## 第一輪：基本接管

| 動作 | 通過判據 | 結果 |
| --- | --- | --- |
| 在測試 VM 由 1U 安裝並啟用虛擬裝置，啟動 helper | 十秒內 FxSound Speakers 成為預設，聲音從原輸出裝置出來 | NOT RUN |
| 分別播放播放器與遊戲音訊，切換效果／bypass | 兩者均經引擎，bypass 恢復原聲，不切預設裝置 | NOT RUN |
| 查三個預設角色 | 記錄 eConsole、eMultimedia、eCommunications；確認只切 eConsole 是否足夠 | NOT RUN |
| 修改 EQ／高音／五項效果，退出 1U | 聲音及最後參數繼續生效 | NOT RUN |
| `quit` 與 `stop` 各執行一次 | helper 退出，預設與原音量／靜音還原 | NOT RUN |

## A4 量測

三個緩衝值各測 20、40、80 ms；緩衝值不是實際端到端延遲。以同一個脈衝或同一段可對位訊號比較輸入與輸出，記錄擷取方式、取樣率、聲道、實體裝置、Windows 版本及原始量測檔。不要向開發機的實體装置播放測試音。

| Buffer ms | 實際延遲 ms（方法／重複次数） | underrun／爆音（觀察時間） | CPU／記憶體 | 結果 |
| --- | --- | --- | --- | --- |
| 20 | 未量測 | 未量測；目前 stats.underruns:null | 未量測 | NOT RUN |
| 40 | 未量測 | 未量測；目前 stats.underruns:null | 未量測 | NOT RUN |
| 80 | 未量測 | 未量測；目前 stats.underruns:null | 未量測 | NOT RUN |

同一檔位連續播放至少 65 分鐘，量開始、30 分鐘、65 分鐘時的延遲，並記錄是否週期性爆音／重新初始化。兩分鐘沒有聲音後，以 PowerShell 執行唯讀 `powercfg /requests`，保存原始輸出；虛擬裝置的 request override 由會話 B 安裝程式處理，實體裝置若仍阻擋睡眠，才據此决定是否加入靜音停流。沒有數據前不改 MMCSS、漂移補償或音訊迴圈，也不把 40 ms 定為已驗證預設。

## 完整 1U 內測

會話 B 的完整測試还需驗登入自動啟動、Windows 停用啟動項、升級不中斷、卸載、官方先後安裝顺序、舊元件升級、HVCI、Win10／Win11、藍牙／USB 7.1／空間音效與反作弊。至少八台、機型分布與零例無法自行恢复声音的判据以主 plan §12 為準；本 helper 的離線自測不能替代它們。

## 內測群文案（測試版就緒後使用）

需要测试功能：音效增强的新音效引擎。  
音效增强 → 本地调音 → 开启增强、切换预设与旁路；确认播放器和游戏声音都能正常改变，关闭后恢复原输出与音量。

需要测试功能：音效增强的装置切换与恢复。  
音效增强 → 本地调音 → 插拔耳机、锁定后解锁、睡眠后唤醒；确认声音回到正确装置，没有异常变大或持续无声。

需要测试功能：音效增强的延迟与持续播放。  
音效增强 → 本地调音 → 分别选择三个延迟档并持续播放；记录实际延迟、爆音及一小时后的变化。

通過標準：至少八台，涵蓋 Win10／Win11、HVCI 開啟、藍牙耳機及 USB 7.1；全部完成接管／關閉／異常退出復原，零例無法自行恢復聲音。量測另依 A4 表格填寫，沒有回報不能判為 PASS，測試版需包含公開對應來源並由會話 B 製成 NSIS 安裝版。
